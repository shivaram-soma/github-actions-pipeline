# Pipeline Troubleshooting Runbook

## Pipeline Failed

### Investigation

1. Open GitHub Actions
2. Select failed workflow
3. Check logs

### Common Causes

- YAML syntax errors
- Missing files
- Lint failures
- Formatting issues

### Resolution

- Fix errors
- Commit changes
- Re-run workflow

---

## Pull Request Check Failed

### Investigation

Review PR check logs.

### Resolution

Correct reported issues and push updates.
