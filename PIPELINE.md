# CI/CD Pipeline Documentation

## Trigger Events

### Push Event

Pipeline runs when code is pushed.

### Pull Request Event

Pipeline runs when a pull request is created.

---

## Stages

### Stage 1: Checkout Code

Downloads repository source code.

### Stage 2: Validation

Verifies repository structure.

### Stage 3: Linting

Checks code quality.

### Stage 4: Formatting

Ensures consistent code style.

### Stage 5: Result

Pipeline passes or fails.
